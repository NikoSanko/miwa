本文は、フロントマターを除いた Markdown を HTML に変換して出力する。変換では表、取り消し線、タスクリスト、脚注を有効にする。Markdown 中の生の HTML は HTML として描画しない。HTML コメントは出力せず、警告も出さない。判定は、HTML ブロックでは最初の行が `<!--` で始まるときそのブロック全体を出力しない。インラインの生 HTML では `<!--` で始まるものを出力しない。それ以外のブロックの生 HTML はエスケープして `<pre>` で囲んで表示し、インラインの生 HTML はエスケープして文字としてそのまま表示する。公開物にスクリプトなどが紛れ込むのを防ぐため。
