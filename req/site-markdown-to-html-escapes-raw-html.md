本文は、フロントマターを除いた Markdown を HTML に変換して出力する。変換では、表、取り消し線、タスクリスト、脚注を有効にする。Markdown 中の生の HTML は、公開物にスクリプトなどが紛れ込むのを防ぐため、HTML として描画しない。

HTML コメントは出力せず、警告も出さない。判定は次のとおりとする。HTML ブロックでは、最初の行が `<!--` で始まるとき、そのブロック全体を出力しない。インラインの生 HTML では、`<!--` で始まるものを出力しない。それ以外のブロックの生 HTML は、その中の `<!--` から `-->` までの部分を取り除いてから、エスケープして `<pre>` で囲んで表示する。それ以外のインラインの生 HTML は、エスケープして文字としてそのまま表示する。
