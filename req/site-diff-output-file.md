---
type: Requirement
id: FR-109
---
`miwa site --diff` の `--out` は、ディレクトリではなく出力するファイルのパスを取る。既定は `_site-diff.html` とし、相対パスはリポジトリルートからの相対として扱う。パスの形は制限しない（絶対パスや `..` を含むものも使える）。

出力先に何かが既に存在するときは、エラーとして何も書かず、exit 1 を返す。存在するものの種類（通常のファイル・ディレクトリ・シンボリックリンク。壊れたリンクを含む）は問わない。既存のファイルは上書きせず、削除もしない（`--out` の指定ミスで元の文書を消す事故を防ぐため）。この確認は比較より前に行う。そのため、変更が無くて何も出力しない場合（FR-110）にも、出力先が存在すれば exit 1 になる。

出力先の親ディレクトリが無いときは作る。書き出しの途中で失敗したときは、部分的なファイルが残ることがある。
