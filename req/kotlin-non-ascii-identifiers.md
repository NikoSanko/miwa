---
type: Requirement
id: FR-063
---
Kotlin では、関数名・型名・バッククォートで囲んだ名前に、漢字・カタカナ・ハングルなどの非 ASCII 文字を含むテストも抽出できる。識別子と内容（ハッシュの対象）は、元のソースの文字のまま記録される。非 ASCII の文字リテラルを含むファイルや、BOM 付きのファイルも同様に扱える。マーカーも、元のソースのコメントから取る。非 ASCII 文字を含む `[正常系]` のような角括弧は、マーカーにならない。非 ASCII 文字を含む行では、構文エラーの検知が緩くなることがある。ただし、緩くなるのは構文エラーを見逃す方向で、有効なコードが `invalid` になる方向ではない。

注釈を2つ以上持ち supertype のないクラスの本体に、注釈付き inner class がある場合も、クラス注釈を無視して抽出する。また、直前にトップレベルの宣言とコメントがあり、位置引数付きの注釈（`@Suppress("LongParameterList")` など）が付いた宣言で、構文解析器の不具合により注釈が宣言から切り離されて認識される場合も、その注釈を無視して抽出する。構文解析器がファイル先頭レベルで宣言以外の構造を返した場合、つまり解析器の不具合で宣言が認識できなかった場合は、黙って test 0件にせず、構文エラーとして invalid にする。
