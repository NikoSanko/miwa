type: Requirement
id: FR-063
---
Kotlin では、関数名・型名・バッククォートで囲んだ名前に漢字・カタカナ・ハングルなどの非 ASCII 文字を含むテストも抽出でき、識別子と内容（ハッシュの対象）は元のソースの文字のまま記録される。非 ASCII の文字リテラルを含むファイルや、BOM 付きのファイルも同様に扱える。マーカーも元のソースのコメントから取る（非 ASCII 文字を含む `[正常系]` のような角括弧はマーカーにならない）。非 ASCII 文字を含む行では、構文エラーの検知が緩くなることがある（有効なコードが `invalid` になる方向ではない）。
注釈を 2 つ以上持ち supertype のないクラスの本体に注釈付き inner class がある場合も、クラス注釈を無視して抽出する。構文解析器がファイル先頭レベルで宣言以外の構造を返した場合（解析器の不具合で宣言が認識できなかった場合）は、黙って test 0 件にせず構文エラーとして invalid にする。
