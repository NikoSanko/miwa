---
type: Requirement
id: FR-126
---
`.miwa/config.yaml` の `judge` は省略可能な節とし、その中の `threshold` と `max_body_bytes` も、それぞれ省略可能とする。次のいずれの場合も、`threshold` と `max_body_bytes` を指定していないものとして扱う。
- `judge` の節がない
- 値のない `judge:` だけがある
- `judge` が `null`（`~` を含む）である
- `judge` が空のマップ（`judge: {}`）である

節の中の各項目も、省略した場合と `null`（値のない `threshold:` や `~` を含む）の場合は、指定していないものとして扱う。指定していない項目には既定値を使う。既定値は `threshold` が 0.9、`max_body_bytes` が 200000 で、`init` が生成する値（FR-019）と同じとする。したがって、省略を含む設定の読み込み結果は、既定値を明示した設定と同じになる。

指定した値には、FR-020 の制約をそのまま適用する。次の場合は、設定エラーとして実行を停止する（exit 1）。
- `threshold` に数値でない値（文字列・真偽値・配列・マップ）を指定した
- `max_body_bytes` に整数でない値（小数、文字列など）を指定した
- `judge` が、`null` でもマップでもない値（`judge: 1` や `judge: []` など）である

この扱いは、`judge` だけでなく、`.miwa/config.yaml` を読み込むすべてのコマンドで同じとする。miwa 0.7.0 が受理していた設定は、すべて同じ値のまま受理する。
