type: Requirement
id: FR-084
---
`miwa index` は、`index` の根に `index.md` がなく担当範囲に文書があるとき、`index.md` を新規に作る。内容は担当範囲の文書をパス順に `- [<タイトル>](<パス>) — <要約>` の平坦な箇条書きにしたもので、見出しは作らない（パスがディレクトリを示す）。書式は FR-082 の追加と同じで（タイトルと要約の `\` `[` `]` を `\\` `\[` `\]` にエスケープする）、`description` が無い文書は区切りと要約を付けない。根の索引を新規作成するとき、子孫に索引があれば、文書の後にそのディレクトリエントリ `- [<相対ディレクトリ>](<相対ディレクトリ>/) — ` も加える（FR-082 と同じ書式）。文書が 0 件の根では何も作らない。
