---
type: Requirement
id: FR-123
---
Dart / Flutter では、ソース直下にある関数 `main` の本体の直下、または有効な `group(...)` のコールバック本体の直下にある文のうち、`test(...)` / `testWidgets(...)` の呼び出し文を test として抽出する。`main` の戻り値型（`void` / `Future<void>`）や `async` の有無は問わず、`main` が無いファイルの test は 0 件とする（invalid にはしない）。

呼び出し先は、修飾のない識別子 `test` / `testWidgets` / `group` に限る。第1引数が文字列リテラルであるものだけを対象とし、`skip:` `variant:` `timeout:` `tags:` などの名前付き引数は無視して、静的な1定義を1件の test とする。`test` / `testWidgets` は、第2引数の形（`async` の有無、`=>` 本体）を問わない。`group` は、第2引数が関数式で、その本体が `{ ... }` のブロックのときだけ、その直下へ降りる。

次の書き方は無視する（invalid にはしない）。
- `t.test(...)` のような prefix 付きの呼び出しや、`test(...).foo()` のようなメソッドチェーン。
- `await test(...)` のように、式文そのものが呼び出しでないもの。
- 第1引数が変数や補間を含む文字列であるもの。名前が動的な `group` は、配下をすべて走査しない。
- 通常の関数の中、test のコールバックの中、`for` / `if` の内部、ヘルパー関数経由で登録されるもの。
