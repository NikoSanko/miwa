id: FR-099

本文中のリンクが公開されない場合は、`<a>` を出さずにリンク文だけを残す。このとき、警告を標準エラーへ 1行 1件、`warning: <元ファイルのリポジトリ相対パス>: unpublished link: <リンク先>` の形で出す。`<リンク先>` は、pulldown-cmark が解釈した destination（FR-076 と同じ。`<…>` や title 属性を除く）とする。含まれる制御文字（Rust の `char::is_control`）は、`\u{1b}` の形にエスケープして出す（端末やログへの制御文字の注入を防ぐため）。

警告の並びは、ページを元ファイルのリポジトリ相対パスのバイト順に並べ、ページ内はリンクと画像（FR-100）を区別せず出現順とする。ただし FR-103 の missing index の警告は、ページの警告より前に、`index` 設定の順で出す。

公開されないリンクは、次のとおりとする。`http:` `https:` `mailto:` 以外のスキーム（`javascript:` など）のリンク、`/` で始まるリンク、空のリンク、解決するとリポジトリの外へ出るリンク、解決先がページとして公開されないリンク（存在しない、`type` が無い、`log.md`、除外対象、`.md` 以外のファイルなど）である。警告があっても、終了コードは 0 のままである。
