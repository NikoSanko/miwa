---
type: Requirement
id: FR-107
---
相対リンクと相対の画像のパスは、次の順で解決する。まず `#` 以降をフラグメントとして分ける。次に、パス側から `?` 以降を捨てる（`?query` は保持しない）。残りをパーセントデコードし、元ファイルのディレクトリ基準で `./` と `..` を正規化する。FR-070 との違いは `?` の扱いだけである（デコード後に現れる `#` を再び分割しないことも同じ）。空の destination、および `?` を捨てた結果のパスが空のものは、空のリンクとして、公開されないリンクに扱う。

出力する href は、解決したパスの各セグメントを RFC 3986 の pchar 以外についてパーセントエンコードし、保持したフラグメントを `#` で付けたものとする。保持したフラグメントは、RFC 3986 の fragment で許される文字（pchar と `/` `?`）以外をパーセントエンコードする。ただし、有効な `%XX`（`%` の後に 16 進数字 2 つ）の 3 文字組はそのまま保持し、それ以外の `%` は `%25` にする（例: `#%E6%A6%82` はそのまま、`#100%` は `#100%25`）。href の最初のセグメントに `:` が含まれるときは、`%3A` にする（スキームと誤解されないため）。
