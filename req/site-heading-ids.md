本文の見出しには `id` 属性を付け、ページ内リンク（`#frag`）で飛べるようにする。値は GitHub の規則に近く、次の順で求める。まず、見出しの描画後のプレーンテキスト（テキストとコードスパンの中身を連結したもの。インラインの生 HTML は、コメントも含め、含めない）の前後の空白を除く。次に、（Unicode の）小文字にする。次に、Unicode の文字・数字（Rust の `char::is_alphanumeric` が真のもの）、`-`、`_`、ASCII の空白（U+0020）以外を取り除く（タブや全角空白（U+3000）もここで取り除かれる）。最後に、ASCII の空白を `-` に置き換える。この規則を当てた結果が空のときは、`id` を付けない。

同じページ内で値が重複したときは、2つ目から `-1`、`-2` の順に付ける。重複の判定では、そのページの脚注のラベル（pulldown-cmark が脚注の `id` に使う値）を先に使用済みとして扱う。見出しの `id` がそれと重ならないよう、`-1` などを付ける。
