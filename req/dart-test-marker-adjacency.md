---
type: Requirement
id: FR-124
---
Dart / Flutter の test に対するマーカーは、`test(...)` / `testWidgets(...)` の呼び出し文の直前に空行を挟まず隣接するコメント（`//` または `/* */`）に書いた `[req id]` から取る。マーカーコメントが存在しない、または空行を挟んで離れている場合、そのテストはマーカーなしとして無視する。マーカーコメントは行頭から始まるものに限り（FR-064）、本文は `[req id]` のトークンだけに限る（FR-121）。

ドキュメントコメント（`///` と `/** */`）はマーカーにしない。dartdoc の参照記法 `[Foo]` と衝突するためである。マーカーコメントと呼び出し文の間にドキュメントコメントが挟まっていても、マーカーは有効とする。
