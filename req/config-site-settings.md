---
type: Requirement
id: FR-094
---
`.miwa/config.yaml` の `site` は省略可能な節で、`title` と `description` をいずれも省略可能な文字列として持つ。省略時と `null`（`site:` の節そのものが null の場合も含む）は、どちらも指定されていないものとして扱う。文字列でない値は設定エラーとする。文字列は前後の空白を除いた値を使い、前後の空白を除いた値が空のとき、または除いた値が改行（LF または CR）を含むときは設定エラーとして実行を停止する（exit 1）。YAML の折り畳みスカラー（`>`）の末尾の改行は除かれるので有効である（FR-071 と同じ）。この検証は他の設定項目と同じく、`miwa site` に限らずすべてのコマンドで行う。`site` の値は `miwa site` 以外のコマンドの出力に影響しない。
