すべての言語で、マーカーとして採用するコメントは、行頭から始まるものに限る。行頭から始まるとは、コメントの開始位置より前の同じ行に、空白文字または BOM 以外の文字がないことをいう。インデント付きのコメントは、行頭から始まるものとして扱う。

前の宣言の末尾に書いた行コメント（`fn x() {} // [FR-001]` など）は、次の test の直前に隣接していても、マーカーとして扱わない。
同じ行に複数のコメントがある場合、2 つ目以降のコメントは行頭から始まるものではないとして扱い、そこでマーカーの探索を打ち切る。その行の先頭にあるコメントも読まない。
