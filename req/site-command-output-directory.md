---
type: Requirement
id: FR-089
---
`miwa site [--out <dir>]` は、閲覧用の静的 HTML 一式を出力先ディレクトリへ書き出す。出力先の既定は `_site` とする。`--out` の相対パスは、リポジトリルートからの相対として扱う。出力先が存在しないときは作り、存在して空のときはそのまま使う。

次のいずれかの場合は、エラーとして何も書かず、exit 1 を返す。

- 出力先が存在して空でないとき（ファイル・ディレクトリを問わずエントリが1つでもあるとき）
- 出力先がディレクトリではなくファイルとして存在するとき
- 出力先がシンボリックリンク（壊れたリンクを含む）のとき

出力先の削除や既存ファイルの上書きはしない（`--out .` のような指定で既存のファイルを消す事故を防ぐため）。

書き出しの途中で失敗したときは、出力先に部分的な出力が残ることがある。その場合は出力先を空にしてからやり直す。
