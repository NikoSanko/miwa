id: FR-113
---
`miwa site --diff` は、索引ページ（`index.md`）を `id` ではなくパスで対応づける。索引ページは文書ではないので、FR-112 の `id` の検査の対象にしない。

追加・削除された索引ページと、タイトル・要約（FR-096 の規則で決まるもの）・本文（フロントマターを除いた Markdown の原文）のいずれかが変わった索引ページは、差分の対象にする。表示に現れないフロントマターのキーだけが変わった索引ページは、対象にしない。ディレクトリを移動したときは、旧パスの削除と新パスの追加として出す（移動としては扱わない）。

索引ページの本文は、`miwa site` が索引ページとして描画する内容（エントリの一覧）を、ブロックに分けて比べる。
