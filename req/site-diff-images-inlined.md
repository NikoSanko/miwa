`miwa site --diff` は、本文中の画像のうち、FR-100 の条件（探索で列挙される、`docs` または `requirements` の配下、拡張子が png / jpg / jpeg / gif / webp）を満たすものを、`data:` URI として HTML に埋め込む。ダウンロードした HTML をそのまま開いても画像が表示されるようにするためである。svg は埋め込まない。変更前の画像は変更前の時点のファイルから、変更後の画像は作業ツリーのファイルから読む。埋め込むのは、出力する文書が参照している画像だけである。

`https:` の画像は、FR-100 と同じくそのまま参照する。条件を満たさない画像は、`<img>` を出さず、代替テキストだけを残す。警告は出さない（FR-114）。

画像を差し替えたブロック（同じパスで内容が違う、または参照先が違う）は、変わったブロックとして左右に並べる。画像だけで文字が無いブロック（代替テキストが空など）も、同じパスの差し替えと参照先の変更のどちらも、左右の対にする。
