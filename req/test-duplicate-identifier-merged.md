---
type: Requirement
id: FR-057
---
マーカーを持つ test の識別子が、言語を問わずリポジトリ全体で重複している場合（C# や Java のオーバーロード、Rust の `#[cfg]` 分岐による同名関数、TypeScript / JavaScript の同名 test など）、それらの出現をまとめて 1 つの test として扱う。その test の内容（ハッシュの対象）は、各出現の内容をソース順（ファイルパス順、同一ファイル内では出現順）に改行で連結したものとする。どれか 1 つの出現が変わっても、出現の順序が入れ替わっても、drift として検知される。

まとめられるのは、すべての出現のマーカーが同じ req を指す場合に限る。異なる req を指す出現が混在する場合は、その識別子のすべての出現を `invalid` とし、識別子ごとに 1 件報告する（詳細に出現ファイルと req id を列挙）。この場合、依存関係は作らない。

マーカーのない出現、およびマーカーが 2 件以上ある出現（FR-014 で invalid）は、まとめる対象に含めない。
