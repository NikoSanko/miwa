---
type: Requirement
id: FR-057
---
マーカーを持つ test の識別子が、言語を問わずリポジトリ全体で重複している場合（C# のオーバーロード、TypeScript の同名 test、Go の同一パッケージの別ファイルにある同名 Test、Rust の `#[cfg]` 分岐による同名関数など）、重複するすべての出現を `invalid` として識別子ごとに1件報告し、詳細に出現したファイルを列挙する。重複した test は依存関係（ノード・エッジ）を作らず、複数マーカーなど他の invalid 理由は重ねて報告しない。マーカーを持たない test は重複の検査対象としない。
