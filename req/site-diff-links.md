type: Requirement
id: FR-119
---
`miwa site --diff` は、本文中のリンクを次のように扱う。リンク先のパスは、FR-107 の規則で解決する。

- `http:` `https:` `mailto:` と、ページ内の `#` だけのリンクは、そのまま残す。
- 解決先が、差分の HTML に含まれる文書（FR-116 の枠）のときは、その枠のアンカー（`#d3` など）へのリンクにする。フラグメントがあるときは、リンク元と同じ側（変更前のブロックなら変更前、変更後のブロックなら変更後）のその文書の見出し id（下の接頭辞付き）へのリンクにする。
- 解決先が、差分に含まれない文書（変わっていない文書など）の元の `.md` のときは、`--link-base` と、その `.md` のリポジトリ相対パスをつないだ URL へのリンクにする。パスは、`miwa site` のリンクと同じ規則でパーセントエンコードする。フラグメントは `#<フラグメント>` として後ろに付ける。
- 上のどちらにもならないとき（`--link-base` が無い、公開されない、リポジトリの外を指す、`javascript:` などのスキームなど）は、リンクを外して文字だけを残す。警告は出さない（FR-114）。

`--link-base` は `http:` または `https:` で始まる URL だけを受け付ける。それ以外の値は、エラーとして何も書かず、exit 1 を返す。末尾に `/` が無いときは補う。

見出し id とページ内リンクの `id` は、文書と側を表す接頭辞（`d3-b-` が変更前、`d3-h-` が変更後。数字は文書のアンカーの番号）を付けて、文書間・左右で衝突しないようにする。
