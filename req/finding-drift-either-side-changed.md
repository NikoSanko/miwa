ロックに記録されたエッジについて、次の場合に `drift` を報告する。
- doc または req のハッシュが、合意時から変化している
- test または req のハッシュが、合意時から変化している

両端が同時に変化した場合も、`drift` を1件として報告する。同様に、ノードの要約または本文のハッシュが合意時から変化している場合は、その `desc` エッジ（FR-086）について `drift` を報告する。`drift` には、どちら側が変化したか（doc / req / test / 両側）を示す理由コードを付ける。`desc` エッジでは要約 / 本文 / 両方を区別し、コードは FR-088 に定める。
