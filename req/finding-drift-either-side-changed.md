type: Requirement
id: FR-024
---
ロックに記録されたエッジについて、doc または req のハッシュが合意時から変化していれば `drift` を報告する。同様に、test または req のハッシュが合意時から変化していれば `drift` を報告する。両端が同時に変化した場合も `drift` を1件として報告する。同様に、ノードの要約または本文のハッシュが合意時から変化していれば、その `desc` エッジ（FR-086）について `drift` を報告する（理由コードは FR-088）。`drift` には、どちら側が変化したか（doc / req / test / 両側。`desc` エッジでは要約 / 本文 / 両方で、コードは FR-088 に定める）を示す理由コードを付ける。
