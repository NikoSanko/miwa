---
type: Requirement
id: FR-101
---
req ページの末尾には、その req への doc から req へのエッジを持つ doc の一覧を、HTML を直接組んで出す。見出しは `<h2>この要求を参照している文書</h2>`、その下に `<ul><li><a href="../docs/x.html">タイトル</a></li></ul>` の形で、doc ごとに 1 項目とする（同じ doc から複数のリンクがあっても 1 項目）。タイトルは FR-096 の規則で決め、href はそのページからの相対パスとする。並びは doc のリポジトリ相対パスの順で決定的にする。参照している doc が無いときは、見出しも含めて節ごと出さない。doc ページ、索引の対象文書、索引ページにはこの節を出さない。
