---
type: Requirement
id: FR-101
---
req ページの末尾には、doc から req へのエッジでその req を指している doc の一覧を、HTML を直接組んで出す。見出しは `<h2>この要求を参照している文書</h2>` とし、その下に `<ul><li><a href="../docs/x.html">タイトル</a></li></ul>` の形で、doc ごとに 1項目を置く（同じ doc から複数のリンクがあっても 1項目）。タイトルは FR-096 の規則で決め、href はそのページからの相対パスとする。並びは doc のリポジトリ相対パスの順とし、決定的にする。

参照している doc が無いときは、見出しも含めて節ごと出さない。doc ページ、索引の対象文書、索引ページには、この節を出さない。
