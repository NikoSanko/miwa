type: Requirement
id: FR-045
---
`review` のエッジが1件以上ある場合、`judge` は設定 `judge.llm_command`（文字列の配列。先頭が実行ファイル、残りが引数）を、エッジの数にかかわらず1回だけ子プロセスとして起動する。プロンプトは標準入力で渡し、作業ディレクトリはリポジトリルートとする。子プロセスの stdout / stderr は `judge` が加工せずそのまま出力する（内容を解釈しない）。`review` のエッジが0件の場合は起動しない。子プロセスの終了コードが 0 以外の場合、または起動に失敗した場合（コマンドが見つからない等）は、実行エラーとして exit 1 とする。エラー出力に API キーの値を含めない。
