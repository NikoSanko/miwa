---
type: Requirement
id: FR-060
---
Java と Kotlin の test に対するマーカーは、コメント（`//` または `/* */`）に書いた `[req id]` から取る。対象のコメントは、メソッド（関数）宣言の直前に、空行を挟まず隣接するものである。メソッド（関数）宣言には、先頭の注釈・修飾子を含む。

doc コメント（`/** */` で始まる Javadoc / KDoc）はマーカーとして扱わない。KDoc の `[Foo]` 参照が req id と衝突するためである（C# では `///` のコメントもマーカーとして扱う点と異なる）。doc コメントは、マーカーとして読まない一方で、隣接するコメントのまとまりを打ち切らない。例えば `// [FR-001]` の後ろに doc コメントを挟んでも、マーカーは有効である。

注釈と署名の間、または注釈同士の間に書いたコメントも、マーカーとして扱わない。マーカーコメントが存在しない場合、または空行を挟んで離れている場合、そのテストはマーカーなしとして無視する。マーカーコメントは、行頭から始まるものに限り（FR-064）、本文は `[req id]` のトークンだけに限る（FR-121）。
