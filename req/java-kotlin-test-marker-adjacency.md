---
type: Requirement
id: FR-060
---
Java と Kotlin の test に対するマーカーは、メソッド（関数）宣言（先頭の注釈・修飾子を含む）の直前に空行を挟まず隣接するコメント（`//` または `/* */`）に書いた `[req id]` から取る。doc コメント（`/** */` で始まる Javadoc / KDoc）はマーカーとして扱わない。KDoc の `[Foo]` 参照が req id と衝突するためである（C# では `///` のコメントもマーカーとして扱う点と異なる）。doc コメントは、マーカーとして読まない一方で、隣接するコメントのまとまりを打ち切らない（`// [FR-001]` の後ろに doc コメントを挟んでもマーカーは有効）。注釈と署名の間、または注釈同士の間に書いたコメントもマーカーとして扱わない。マーカーコメントが存在しない、または空行を挟んで離れている場合、そのテストはマーカーなしとして無視する。マーカーコメントは行頭から始まるものに限る（FR-064）。
