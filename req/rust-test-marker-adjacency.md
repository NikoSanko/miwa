---
type: Requirement
id: FR-016
---
Rust の test 関数に対するマーカーは、その `fn` に付いた test 属性のうちソース上で最初に現れるものの直前に、空行を挟まず隣接するコメントに書く。属性同士の間や、属性と `fn` の間にあるコメントはマーカーとして扱わない。マーカーコメントが存在しない、または空行を挟んで離れている場合、そのテストはマーカーなしとして無視する。`rust.test_attributes` に属性を追加すると「最初の test 属性」が変わり、マーカーを置くべき位置も変わり得る。doc コメント（`///` `//!` `/** */` `/*! */`）はマーカーとして扱わない。rustdoc の `[Foo]` リンク参照が req id と衝突するためである。doc コメントは、マーカーとして読まない一方で、マーカーコメントと test 属性の間に挟まっていてもマーカーは有効とする（`// [FR-001]` の後ろに `/// doc` を挟んでもよい）。`////` や `/***` のように doc コメントでないものは通常のコメントとして扱う。マーカーコメントは行頭から始まるものに限る（FR-064）。
