---
type: Requirement
id: FR-121
---
すべての言語で、マーカーとして採用するコメントは、コメント記号（`//` `///` `/* */` `/** */`、複数行のブロックコメントでは各行先頭の `*` の装飾も含む）と前後の空白を除いた本文が、空白（改行を含む）で区切られた `[req id]` のトークンだけからなるものに限る。コメント記号は種別ごとに1組だけ除く（行コメントは `//` と、続く `/` 1文字まで。ブロックコメントは `/*` と、続く `*` 1文字まで、および末尾の `*/`）。`////` や `/***` の余分な記号は本文の一部とみなすので、そのコメントはマーカーにならない。トークンが1つならマーカーとし、2つ以上ならマーカーが複数あるものとして扱う（FR-014）。

本文にトークン以外の文字が含まれるコメント（`// [FR-001] 説明` や `// 説明 [0] 説明` など）は、角括弧を含んでいても、マーカーを持たない通常のコメントとして扱う。この場合、そのコメントはマーカーなしとして無視し、test を `invalid` にもしない。マーカーを書いた行に説明も書きたいときは、マーカーだけの行と説明の行に分ける。doc コメントの扱いは、各言語のマーカー要件のとおりである。
